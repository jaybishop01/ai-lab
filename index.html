Make your data AI ready with dbt and Snowflake

Set up both accounts before we start building · about 10 minutes total

Part 1 · dbt platform account ~5 min

  1. Open a private / incognito browser window. (If you're already logged in to dbt, signup can misbehave.)
  2. Go to workshops.us1.dbt.com/workshop.
  3. Fill in your name and work email. For Workshop, pick Make your data AI ready with dbt and Snowflake.
  4. Enter the passcode shown on the screen, agree to the terms, and click Complete registration.
  5. Screenshot the login page (your email and password), then click Log In.

You're set when: you're in dbt platform and can open Studio on the workshop project.

Lost your login? Your email is usually firstname.lastname@dbtlabsworkshop.com. Ask a facilitator for the password or a reset.

Part 2 · Snowflake lab data ~5 min

1. Copy the setup SQL

Fetching setup file…

Button not working? Download bootstrap.sql and open it, or view it on GitHub → Raw → select all.

2. Run it in Snowflake

  1. Log in to your Snowflake lab account and open Projects → Worksheets → + → SQL Worksheet.
  2. At the top of the worksheet, use the context selector to pick your lab database.
  3. Paste, then click the ▶ dropdown → Run All. Wait about a minute.

3. Check it worked

select count(*) from INDUSTRIES_HIGHER_EDUCATION.HED_RECORDS;             -- 750
show semantic views in schema sv_higher_education;                        -- SV_HED_AT_RISK_STUDENTS
select count(*) from sv_higher_education.vw_hed_retention_risk_analysis;  -- 257 at-risk students

You're set when: the three checks return 750, one semantic view, and 257.

Fell behind?

  • Re-running is safe. Paste and Run All again.
  • First result is NULL: no database selected. Pick one in the context selector.
  • “Insufficient privileges” or the semantic view fails: raise your hand.
