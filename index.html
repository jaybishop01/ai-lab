Snowflake lab setup · about 2 minutes

1. Copy the setup SQL

Fetching setup file…

Button not working? Download bootstrap.sql and open it, or view it on GitHub → Raw → select all.

2. Run it in Snowflake

  1. In your Snowflake lab account, open Projects → Worksheets → + → SQL Worksheet.
  2. At the top of the worksheet, use the context selector to pick your lab database.
  3. Paste, then click the ▶ dropdown → Run All. Wait about a minute.

3. Check it worked

select count(*) from INDUSTRIES_HIGHER_EDUCATION.HED_RECORDS;             -- 750
show semantic views in schema sv_higher_education;                        -- SV_HED_AT_RISK_STUDENTS
select count(*) from sv_higher_education.vw_hed_retention_risk_analysis;  -- at-risk students

Fell behind?

  • Re-running is safe. Paste and Run All again.
  • First result is NULL: no database selected. Pick one in the context selector.
  • “Insufficient privileges” or the semantic view fails: raise your hand.
